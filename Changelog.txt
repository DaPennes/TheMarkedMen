== Changelog ==

Added
- Equipped weapons now get quality and durability applied, just like clothes
- Infected pawns can no longer wear shield belts (they are too feral to use them)
- New safety system: if the game can't find a suitable weapon for a pawn, it will grab any weapon available instead of leaving them unarmed
- Missing pawn types (Scouts, Hunters) now get their clothes properly checked like other civilians

Removed
- Removed the weapon blocking system that was causing infected pawns to spawn without weapons
- Removed unused old code that was left over from a previous version

Fixed
- Crossed Civilians no longer get a warning about not being able to afford weapons
- Pawn clothes search now respects the minimum quality tier instead of always looking for the best
- Scouts and Hunters will now have their military gear stripped, just like other civilian pawns
- The weapon fallback option now properly checks that the weapon is usable instead of picking random ones
- Cleaned up unused variables and methods that were cluttering the code

== 2026-07-14 ==

Changed
- Raid countdown alert is now cached per game tick (4x faster UI refresh, no more map iteration per frame)
- Scheduled raid firing moved from every-game-tick to every-maintenance-tick (~41s) to reduce CPU overhead
- Alert code consolidated: string constants extracted, new helper methods for readability

Fixed
- Infected pawns no longer have their gear stripped and dropped post-spawn (AssignEquipment was running twice — once during generation and once on SpawnSetup, the second run dropping gear to the ground)
- Shield belts are now properly blocked on infected pawns during StripDisallowedApparel (the infected check was placed after the shield continue statement, making it unreachable)
- Raid countdown cache invalidates immediately when raid state changes (start/end/schedule)

Removed
- Removed Patch_InfectedEquipmentBlock which was blocking AddEquipment for all infected pawns

Performance
- CrossedTacticalAI.FindBestNonInfectedPawnTarget now caches results for 250 ticks
  (was scanning AllPawnsSpawned + scoring every pawn every 60 ticks per infected pawn)
- KillAnticipation scan interval increased 60->250 ticks (4x reduction, ~1s->4s)
- ScreamingCharge scan interval increased 120->250 ticks
- PackCoordination scan interval increased 120->180 ticks
