# BUILD INSTRUCTIONS - Cure-to-Refugee Feature

## Quick Start

The feature is **100% complete and ready to compile**. Follow these steps:

### Step 1: Close RimWorld
The DLL file is currently locked by the running game. You must close RimWorld completely before building.

### Step 2: Rebuild the DLL
Run this command in your terminal/PowerShell:

```bash
cd "C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods\The Marked Men\Source\TheMarkedMen"
dotnet build TheMarkedMen.csproj -c Release
```

Or use Visual Studio:
- Open `TheMarkedMen.csproj`
- Build > Build Solution (Release mode)

### Step 3: Verify Build Success
You should see:
```
Build succeeded
```

The new DLL will be copied to:
```
Assemblies/TheMarkedMen.dll
```

### Step 4: Launch RimWorld
Start the game and load a save. The feature is now active.

## Test the Feature

1. Load a save with infected pawns (or create a new game and infect a colonist)
2. Apply cure syringe to the infected pawn
3. A **green choice letter** will appear (not red alert):
   - **Title:** "Cured Survivor: [Pawn Name]"
   - **Buttons:** Accept / Reject / Close
4. Click **Accept** to recruit them, or **Reject** to send them away
